# IOFitness brand quiz — decisions

Updated: 2026-09-06. Superseded for day-to-day use by `docs/brand-bible.md`.

## Locked

- **Job:** Help people get better from wherever they are — safe, progressive, honest.
- **Not for:** Ultra-specialized athletes; people who want comforting lies.
- **Truth over comfort:** Real timelines. No sugarcoating. No fake guarantees.
- **Personality:** Warm coach. Calm. Plainspoken. Celebrates real wins. Not demanding. Unapologetically truthful.
- **One voice** across homepage, Learn, app, ads.
- **Claims:** No diagnosis. No guaranteed results. Light evidence OK.
- **Brand line:** Get better.
- **Soft close:** IOFitness is built to…
- **Visual:** Lane D1 — warm paper + forest; Fraunces wordmark only; Source Sans 3 elsewhere; no photography.

## Product frame candidates (all kept)

1. No matter where you’re starting, you can get better. We’ll help you do it safely, progressively, and honestly.
2. You can get better from here. We’ll build the path with you: progressive, safe, and straight with you.
3. Getting better is possible from where you are. We stick with you and program it properly.
